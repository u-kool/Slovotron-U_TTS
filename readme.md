# Словотрон (U_TTS Edition)

Интерактивная игра-угадайка слов для стримов в виде оверлея для **U_TTS**.

Игра слушать чаты всех подключённых в U_TTS площадок (Twitch, VK Video Live, YouTube, GoodGame) через шину WebSocket приложения, озвучивает победителя выбранным TTS-голосом («Голос победы» в настройках оверлея U_TTS) и умеет показывать таблицу лидеров по команде `!слв-топ` / `!словотрон-топ`.

## Как подключить
1. Запустите U_TTS и откройте «Настройки оверлея» → тема **Slovotron**.
2. Скопируйте ссылку виджета и добавьте её как источник браузера в OBS.

## Команды зрителей
| Команда | Действие |
|---|---|
| `!слв-топ`, `!словотрон-топ` | показать таблицу лидеров до конца раунда |
| `!слв-подсказка`, `!slovotron-hint` | подсказка (модераторы) |
| `!слв-рестарт`, `!словотрон-рес`, `!sres` | новый раунд (модераторы) |

---
Базируется на открытом проекте Slovotron; логика игры не изменялась, интеграция с U_TTS — в файлах `js/utts_bridge.js` и `js/utts_settings.js`.
